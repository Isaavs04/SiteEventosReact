# SiteEventosReact
Trabalho em grupo do IFSP campus Cubatão da matéria de desenvolvimento web do curso de ADS

## Organização das Pasta
frontend -> armazena todos os arquivos relacionados a interface.
    src -> é a pasta onde fica os principais arquivos que foram desenvolvidos no React
        pages -> é onde ficam armazenadas as pastas do sistema
        styles -> pasta destinada aos estilos dos arquivos html
        services -> guarda os arquivos responsáveis pela comunicação com serviços externos. ex.: API.
        App.jsx -> é o componente principal da aplicação React
        main.jsx -> arquivo que acontece a inicialização do react e a renderização do componente principal (App) na página HTML


## Configuração do React
Uso de Vite como ferramenta de desenvolvimento frontend que facilita a criação e a excução de projetos com bibliotecas e frameworks como o React


Função de cada Pasta no Back-end

controllers ->	Lógica do login.
middleware -> Verificação do token.
routes -> Definição das rotas da API.
data -> Usuários pré-cadastrados.
server.js -> Configuração e inicialização do servidor.
